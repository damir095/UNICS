# Оценщики владения навыком (тип подплагинов `unicsest`)

Точка расширения адаптивного цикла УНИКС. Новый оценщик добавляется папкой в этот каталог,
править ядро `local_unics` не нужно.

## Контракт

Папка `local/unics/estimator/<имя>/` содержит:

- `version.php` с `$plugin->component = 'unicsest_<имя>';`
- `classes/estimator.php` - класс `\unicsest_<имя>\estimator`, реализующий
  `local_unics\adaptive\mastery_estimator`;
- `lang/ru/unicsest_<имя>.php` со строкой `$string['pluginname']`.

При необходимости подплагин может иметь свои `db/install.xml`, `db/tasks.php`, `settings.php`.

## Что считает подплагин, а что ядро

Подплагин считает только `score` (0..100) и число попыток. Полосы (`пробел` / `в процессе` /
`освоено`) назначает ядро через `local_unics\adaptive\mastery_bands` - иначе оценщики
несопоставимы между собой.

## Выбор реализации

Site administration -> УНИКС -> Адаптивное обучение -> «Оценщик владения навыком». Пустое
значение - встроенный расчет ядра (EWMA). При любом отказе выбранного подплагина (нет класса,
класс не реализует интерфейс, исключение в конструкторе) ядро молча откатывается на встроенный
оценщик: адаптивный цикл не должен падать из-за стороннего компонента.
